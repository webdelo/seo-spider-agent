# ShareSpider

Native macOS 14+ SEO crawler built with Swift 6, SwiftUI, URLSession async/await and SwiftSoup.

Open `Package.swift` in Xcode and run the `ShareSpider` scheme, or run:

```sh
cd ShareSpider
swift run
```

The application supports Spider and List modes, configurable concurrent crawling, pause/resume/stop, metadata extraction, grouped Overview and Issues reports, searchable URL results, and CSV exports.

JavaScript rendering, authentication, Google integrations, Lighthouse, and custom extraction rules are deliberately outside this MVP, per the specification.
